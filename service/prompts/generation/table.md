# 输出格式要求
请严格按照以下 JSON 格式输出，不要输出任何其他文字、解释、Markdown 标记或换行符：
{"table":{"total_rows":总行数,"total_cols":总列数,"cells":[{"r":行号从0开始,"c":列号从0开始,"cs":跨列数默认1,"rs":跨行数默认1,"text":"单元格内容"}]}}

## 字段说明
- `total_rows`：表格总行数（整数）
- `total_cols`：表格最宽列数（整数）
- `cells`：每个单元格的数组，每项包含：
  - `r`：行号（从 0 开始）
  - `c`：列号（从 0 开始）
  - `cs`：跨列数，默认 1
  - `rs`：跨行数，默认 1
  - `text`：单元格内的文字

## 重要规则
1. 只输出纯 JSON，不要 ```json 代码块
2. 被合并的单元格不要出现在 cells 中（如 A1 跨 3 列，则 B1、C1 不写）
3. 如果资料中某个信息缺失，text 填空字符串 ""
4. 跨行合并的单元格只需写一次，被占用的格子不写

# 执行步骤（请按顺序完成） 
**Step 1 - 解析表格结构**                 
阅读 生成要求 和 HTML模板，识别：                
- 每个单元格的位置（r, c）                    
- 合并单元格的跨列数（cs）和跨行数（rs）             
- 表头与数据区域的划分                        
- 根据固定行和一些按数据条数重复的行最终计算出总行数、总列数                           

**Step 2 - 映射填充内容**                 
根据 参考资料 与 生成指令
- 将资料中的字段与表格单元格一一对应                 
- 按生成指令要求处理、转换或生成内容                 
- 缺失信息的单元格 text 填 ""                

**Step 3 - 输出结构化 JSON**             
严格按照输出格式要求，输出最终 JSON，不附带任何额外内容。
